# Bocha Switcher — план

Нативное macOS-приложение в меню-баре, аналог Punto Switcher: исправляет текст, набранный не в той раскладке (`ghbdtn` → `привет`), по хоткею и автоматически.

Основа — [rashn/RuSwitcher](https://github.com/rashn/RuSwitcher) (MIT, Swift 6 + AppKit, macOS 13+, universal binary). Исходный план — [docs/BOCHA_SWITCHER_PLAN.md](docs/BOCHA_SWITCHER_PLAN.md).

## Принятые решения

- **Сборка — GitHub Actions на macOS-раннере.** Разработка идёт на Linux, где AppKit недоступен. Каждый push собирает universal `.app` и DMG; результат скачивается из артефактов.
- **Аудитория — я и несколько друзей.** DMG без Apple Developer ID и нотаризации. Друзья открывают через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» (на macOS 15+ ПКМ → «Открыть» больше не работает).
- **Полный ребрендинг.** Никаких упоминаний RuSwitcher в приложении; `LICENSE` автора остаётся в репозитории без изменений. Вкладки «О программе» нет — авторство будет указано на сайте. Языки — только ru/en. От upstream отрываемся; исправления автора переносим вручную (cherry-pick), remote `upstream` оставляем для этого.
- **Стабильная подпись.** Самоподписанный сертификат хранится в секретах GitHub, CI подписывает им каждую сборку. Иначе при ad-hoc подписи macOS сбрасывает разрешения Accessibility / Input Monitoring после каждого обновления.
- **Ни байта пользовательского текста в сеть, никакой телеметрии.**

## Результаты аудита RuSwitcher

- Сетевые вызовы в приложении есть только в `UpdateChecker.swift`: он скачивает `version.json` / `version-beta.json` и DMG из `raw.githubusercontent.com/rashn/...` и из GitHub Releases.
- Ссылки, открываемые в браузере: Boosty (донаты), Telegram-чат, кнопки «поделиться» (VK, Telegram, X, Facebook, Reddit, WhatsApp), GitHub/issues автора, email автора, Homebrew-cask (`formulae.brew.sh`).
- `telegram/`, `stats/`, `scripts/*.py` — служебные инструменты автора (посты в Telegram-канал, статистика). В приложение не входят — удалить.
- `windows/`, `shared/`, `macos/ruswitcher.rb` (Homebrew-cask), `.github/workflows/` автора — удалить или заменить.
- Переводы хранятся в коде: `macos/Sources/RuSwitcher/Localization.swift`.

## Фазы

### 1. Основа и CI
1. Перенести историю RuSwitcher в этот репозиторий, добавить remote `upstream`.
2. Workflow `build.yml`: `macos-latest`, сборка universal `.app` + DMG, загрузка в артефакты.
3. Собрать оригинал **без изменений** — убедиться, что сборка работает.

**Готово, когда:** CI зелёный, DMG оригинала скачивается и запускается на Маке.

### 2. Отрезать чужое
1. `UpdateChecker` → направить на Releases нашего репозитория (друзьям пригодятся обновления).
2. Удалить донаты, Telegram, кнопки «поделиться», Homebrew, email/issues автора.
3. Удалить `windows/`, `shared/`, `telegram/`, `stats/`, `scripts/`, CI автора.
4. Проверить: в коде не осталось сетевых обращений, кроме проверки обновлений в нашем репозитории.

### 3. Ребрендинг
1. `RuSwitcher` → `Bocha Switcher` (UI) / `BochaSwitcher` (файлы, таргет, модуль, папка исходников).
2. Bundle ID → `world.whyia.bochaswitcher` (домен 501c3.help не используем).
3. Локализации: оставить ru/en.
4. Убрать вкладку «О программе». Версия 1.0.0.

**Готово, когда:** `grep -ri ruswitcher` по коду приложения ничего не находит.

### 4. Бренд
1. Иконка приложения 1024×1024 → `.icns`.
2. Иконка меню-бара: монохромная «Б» / «B» по текущей раскладке.
3. Пасхалка в онбординге: анимация `ищсрф` → `bocha`.

### 5. Подпись и релизы
1. Самоподписанный сертификат → секреты GitHub → подпись в CI.
2. Релиз по тегу `v*`: DMG `BochaSwitcher-X.Y.Z.dmg` в GitHub Releases + `version.json` для автообновления.

### 6. Тестирование
Хоткей и автоисправление в Safari, Chrome, Telegram, Slack, VS Code, Terminal/iTerm, Notes, Mail, Pages. В полях паролей — **не срабатывать**. Отдельно: откат повторным нажатием, выделенный текст, слова с `,.;:` на конце, короткие слова.

## Бэклог
- Детектор из [graninilya/keyswitcher](https://github.com/graninilya/keyswitcher) (MIT; hunspell + n-граммы), если автоисправление окажется слабым.
- Звуки под бренд.
- Apple Developer ID + нотаризация — если аудитория вырастет.

## Правила работы
- Перед каждой фазой — показать план изменений; после — зелёный CI.
- Коммит после каждой завершённой фазы с понятным сообщением.
- Совместимость: macOS 13+, universal binary (arm64 + x86_64).
